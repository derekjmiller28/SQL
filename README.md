# Ecommerce sales sql analysis
This project analyzes **ficticious** Amazon sales data using MySQL to answer core business performance questions. The focus is on writing clean, readable SQL to calculate key sales KPIs and summarize overall business health.

👉[View the project](amazonSQLPROJECT.sql)



# 📂 Dataset

Source: Kaggle – Amazon Sales Dataset

Data Type: Transactional e-commerce sales data

Grain: One row per product per order

The raw CSV was modeled into a relational database to support accurate aggregation and analysis.

# 🛠 Tools & Technologies

Database: MySQL

Language: SQL

Skills Demonstrated:

Aggregations (SUM, COUNT, AVG)

Conditional logic (CASE WHEN)

Multi-table joins

KPI calculations

Basic business interpretation

# ❓ Business Questions Answered 

### This project answers the following foundational business questions:

- What is the total revenue generated?

- How many total orders were placed?

- What is the average order value (AOV)?

- Which product categories generate the most revenue?

- Which products sell the highest quantities?

- What are the top 10 products by revenue?

- How many unique customers placed orders?

- What is the distribution of order statuses?

- What percentage of orders were returned?

- What is the average quantity per order?

# 📊 Key Metrics Calculated

- Total revenue

- Order volume

- Average order value (AOV)

- Return rate

- Product and category sales performance

- Customer count

# 🔍 Sample Insights

A small subset of products accounts for a large portion of total revenue.

Certain categories outperform others consistently in sales volume.

Average order size suggests opportunities for bundling or upselling.
